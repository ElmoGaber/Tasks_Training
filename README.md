# Internship Projects

A collection of four premium frontend projects built with pure HTML, CSS, and JavaScript.

## Projects

### Project 1: Calculator
A modern calculator with glassmorphism design, basic arithmetic operations, percentage, keyboard support, and error handling.
- **Theme:** Deep purple/pink accent
- **Features:** Decimal support, delete button, responsive layout

### Project 2: Password Generator
A secure password generator with customizable options and real-time strength meter.
- **Theme:** Cyber green/blue accent
- **Features:** Length slider, character type toggles, copy to clipboard, strength evaluation

### Project 3: Stopwatch
A precision stopwatch with millisecond accuracy and lap recording.
- **Theme:** Warm amber/orange accent
- **Features:** Start/Pause/Resume/Reset, lap management, keyboard shortcuts

### Project 4: Age Calculator
A detailed age calculator that computes exact age and birthday information.
- **Theme:** Purple/violet accent
- **Features:** Years/months/days breakdown, next birthday, zodiac sign, input validation

## Design System

Each project features:
- Glassmorphism UI with backdrop blur
- Smooth animations and transitions
- Dark modern aesthetic
- Fully responsive (320px - 1440px)
- Accessible with semantic HTML and ARIA labels
- Keyboard navigable

## Technologies

- HTML5
- CSS3 (Flexbox, Grid, Custom Properties, Animations)
- Vanilla JavaScript (ES6+)

## How to View

Open any project's `index.html` file in a modern browser. No build tools, frameworks, or dependencies required.
