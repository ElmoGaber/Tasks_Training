# Stopwatch

A precision stopwatch with lap recording and keyboard shortcuts, featuring a warm amber glassmorphism design.

## Features

- Start, Pause, Resume, and Reset controls
- Millisecond precision display
- Lap recording with individual delete
- Clear all laps
- Keyboard shortcuts (Space = Start/Pause, L = Lap, R = Reset)
- Smooth animations and responsive layout

## Technologies Used

- HTML5
- CSS3 (Flexbox, Animations, Glassmorphism)
- Vanilla JavaScript (ES6+, requestAnimationFrame)

Open `index.html` in any modern browser. No dependencies required.
