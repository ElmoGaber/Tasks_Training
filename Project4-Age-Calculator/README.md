# Age Calculator

A sophisticated age calculator that provides detailed age information including next birthday and zodiac sign.

## Features

- Calculate exact age in years, months, and days
- Total days lived since birth
- Next birthday date and days remaining
- Zodiac sign identification
- Input validation (future dates, invalid dates, range checks)
- Keyboard support (Enter to calculate)
- Purple glassmorphism UI with smooth animations

## Technologies Used

- HTML5
- CSS3 (Grid, Flexbox, Glassmorphism, Animations)
- Vanilla JavaScript (ES6+, Date API)

Open `index.html` in any modern browser. No dependencies required.
