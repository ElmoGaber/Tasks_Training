# Calculator

A modern, responsive calculator application with glassmorphism design, built with vanilla JavaScript.

## Features

- Basic arithmetic operations (+, -, ×, ÷)
- Decimal number support
- Percentage calculations
- Keyboard support
- Clear and Delete buttons
- Error handling (division by zero, overflow)
- Responsive design for all screen sizes
- Glassmorphism UI with smooth animations

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Glassmorphism, Custom Properties)
- Vanilla JavaScript (ES6+)

## Folder Structure

```
Project1-Calculator/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

Open `index.html` in any modern browser. No build tools or dependencies required.
